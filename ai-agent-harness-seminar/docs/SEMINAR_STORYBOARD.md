## 전개

1. Attention·KV Cache에서 LLM이 할 수 있는 일과 도구가 필요한 일로 연결
2. WEF의 에이전트 정의·감지-판단-행동 구조를 코딩 어시스턴트 사례에 대응
3. 에이전트 전체, 하네스, 실행 환경을 역할별로 분리
4. 도구 명세 → 모델의 구조화 호출 → 하네스의 권한 확인 → 도구 실행 → 결과 반환을 시각화
5. Qwen3 Hermes-style 도구 호출 및 OpenAI·Claude 공개 API의 요청/응답 역할을 비교
6. 할인·세금 계산 예제로 테스트 실패와 수정 과정을 설명
7. 자율성·권한, 평가·위험 평가·거버넌스, 제품·확장 도구·실제 사용 사례로 확장
8. 더 단순한 접근과 블로그 작성 과정을 제시하고 요약
