## 편집 기준

- 본문의 용어 정의, 예제, 주장 강도와 단서를 유지합니다.
- 도구 요청과 실제 실행을 구분한 후 합성 코드 기록으로 확인하고, 그 뒤에 API 형식을 보여 줍니다.
- 기본 화면에는 핵심 설명을 두고, 자세한 설명과 출처는 발표자 노트에 둡니다.
- 켄자쿠는 6번 장 하단의 보조 비유로만 사용합니다. 원본 이미지는 비율을 보존해 72×90 CSS px 영역에 표시합니다.
- 제품 개요는 블로그의 공식 자료 확인일(2026-09-23)을 따릅니다. 성능 순위를 매기지 않습니다.
