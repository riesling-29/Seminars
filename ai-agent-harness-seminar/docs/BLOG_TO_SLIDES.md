## 편집 기준

- 슬라이드만 보아도 핵심 개념, 역할 구분, 예시의 맥락을 따라갈 수 있도록 설명을 화면에 둡니다.
- 글자가 출처 푸터와 겹치지 않도록 본문 여백을 확보하고, 한 장에 담기 어려우면 내용을 나눕니다.
- 도구 요청, 하네스의 정책 확인, 실제 실행, 결과 전달을 각기 다른 역할로 보여 줍니다.
- Qwen3 tool-calling 예시는 공식 Hermes-style 형식의 설명용 축약입니다. 실행 결과는 실제 측정치로 오인되지 않게 표시합니다.
- 실제 실행 기록은 무엇을 요청했고 무엇이 반환됐는지, 테스트가 왜 실패했는지를 쉬운 말로 설명합니다.
- 제품 기능은 2026-09-23 공식 자료 확인 기준입니다. 성능 순위로 제시하지 않습니다.
- 켄자쿠 비유와 이미지는 사용자의 요청에 따라 제외합니다.
