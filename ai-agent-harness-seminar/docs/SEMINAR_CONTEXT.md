## 청중

Attention과 KV Cache의 간단한 설명은 배웠지만 잘 기억하지 못한다는 사용자 확인이 있어 복습을 포함합니다. AI Agent, Harness, Tool Calling은 처음일 수 있습니다. 회사 세미나이며, 이전 기획상 하드웨어·Edge Computing·진동진단·플라즈마 시뮬레이션 엔지니어가 대상입니다. 실제 참석자의 상세 숙련도는 미확정입니다.

## 작업 정의

| 용어 | 이 발표에서의 뜻 |
| --- | --- |
| LLM | 입력 맥락에서 다음 출력과 도구 호출 요청을 생성하는 모델 |
| 하네스 | 모델 호출, 맥락·상태·도구 라우팅, 권한·승인·결과 전달·종료를 운영하는 코드 |
| 실행 환경 | 파일과 프로세스, 도구의 실제 동작이 존재하는 공간 |
| 에이전트 | 목표를 받아 위 구성요소로 도구를 사용하고 결과를 다음 판단에 반영하는 전체 시스템 |
| 워크플로 | 단계와 분기를 주로 코드가 미리 정한 흐름 |

정의는 업계의 단일 표준을 주장하지 않습니다. WEF의 넓은 정의와 Anthropic의 workflow/agent 구분을 본문 맥락 안에서 소개합니다.

## 설명과 근거

원문에 있는 사실·해석·예시의 맥락과 주장 강도를 유지합니다. 교육용 API 예시와 실행 기록은 축약·합성임을 표시합니다. Qwen3 tool calling 형식은 공식 문서에 맞추고, 실제 API envelope는 프레임워크에 따라 달라질 수 있음을 밝힙니다. 제품 개요는 블로그의 2026-09-23 공식 자료 확인일을 따르며 발표 직전 재확인합니다.
