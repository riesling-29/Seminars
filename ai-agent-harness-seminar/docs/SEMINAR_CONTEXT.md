## 청중

Attention과 KV Cache의 간단한 설명은 배웠지만 AI Agent, Harness, Tool Calling은 처음일 수 있습니다. 회사 세미나이며, 이전 기획상 하드웨어·Edge Computing·진동진단·플라즈마 시뮬레이션 엔지니어가 대상입니다. 실제 참석자의 상세 숙련도는 미확정입니다.

## 작업 정의

| 용어 | 이 발표에서의 뜻 |
| --- | --- |
| LLM | 입력 맥락에서 다음 출력과 도구 호출 요청을 생성하는 모델 |
| 하네스 | 모델 호출, 맥락·상태·도구 라우팅, 권한·승인·결과 전달·종료를 운영하는 코드 |
| 실행 환경 | 파일과 프로세스, 도구의 실제 동작이 존재하는 공간 |
| 에이전트 | 목표를 받아 위 구성요소로 도구를 사용하고 결과를 다음 판단에 반영하는 전체 시스템 |
| 워크플로 | 단계와 분기를 주로 코드가 미리 정한 흐름 |

정의는 업계의 단일 표준을 주장하지 않습니다. WEF의 넓은 정의와 Anthropic의 workflow/agent 구분을 본문 맥락 안에서 소개합니다.

5. 블로그와 같은 할인·세금 합성 Python 예제의 실제 명령·결과 재생
6. OpenAI와 Anthropic의 공개 API 형식, Hermes 기록 표현의 구분
7. 자율성과 권한, WEF의 분류·평가·위험 평가·거버넌스
8. Claude Code, Codex, OpenCode, Pi, Oh My Pi, Hermes Agent, OpenClaw
9. MCP·스킬·메모리, 작은 실제 과제와 Chat·Script·Workflow·기존 방식 유지 대안
