## 형식과 범위 메모

- Qwen3 공식 문서는 Hermes와 유사한 tool-calling 템플릿을 설명하며 `<tool_call>`와 `<tool_response>` 예시를 제시합니다. 이 덱은 그 구조를 설명용으로 단순화했습니다.
- Qwen 문서는 도구 결과가 대화의 별도 user 메시지로 전달되고 인자 객체를 사용하는 구조를 설명합니다. 세부 API와 실행 구현은 프레임워크·서버에 따라 달라질 수 있습니다.
- OpenAI Function Calling과 Claude tool-use 예시는 공개 API의 모델 호출·애플리케이션 실행·결과 반환 관계를 설명합니다. Claude Code 내부 메시지 형식을 뜻하지 않습니다.
- WEF 2024 Figure 1 및 WEF 2025 Figure 2의 관계는 편집 가능한 자체 SVG로 재구성했습니다.
- 실행 기록은 저장소의 합성 예제를 임시 폴더에서 실행한 내용입니다. 일반적인 제품 성능이나 성공률을 측정한 것이 아닙니다.
- 켄자쿠 비유는 사용자의 요청에 따라 이 덱에서 제외했습니다.
