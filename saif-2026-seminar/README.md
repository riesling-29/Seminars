# SAIF 2026 읽기

삼성 AI 포럼 2026의 공개 자료를 일반 독자에게 설명하는 30개 섹션의 한국어 웹 세미나입니다. 행사일은 2026년 9월 30일(KST), 자료 정리일은 2026년 10월 2일입니다.

- [웹 세미나](https://riesling-29.github.io/Seminars/saif-2026-seminar/)
- [발표 모드](https://riesling-29.github.io/Seminars/saif-2026-seminar/?mode=present)

## 읽는 방법

- **읽기:** 모든 본문과 추가 설명을 이어 읽습니다.
- **발표:** 한 섹션씩 표시합니다. 이전·다음 버튼 또는 좌우 방향키, Page Up/Down을 사용합니다. Home/End는 처음·마지막 장, Escape는 읽기 모드입니다.
- **목차:** 원하는 장으로 이동합니다. Escape 또는 닫기 버튼으로 닫습니다.
- **인쇄 / PDF:** 브라우저 인쇄를 사용합니다. 인쇄 시 모든 장과 추가 설명을 표시합니다.
- 모바일에서는 내용이 길면 세로로 스크롤합니다. 텍스트를 작게 줄여 한 화면에 억지로 맞추지 않습니다.
- 주소의 `#장-id`로 특정 장을 직접 열 수 있습니다.

## 근거와 한계

공식 프로그램·뉴스룸과 Samsung Developer 공식 다시보기의 공개 영어 자동자막을 바탕으로 작성했습니다. 일부 한국어 세션은 자동자막의 문맥이 소실돼 공식 소개·보도에서 확인되는 범위로 구분했습니다. 삼성 DS 일부 사례는 공식 뉴스룸의 발표 사진으로 보완했습니다.

전체 영상의 시청이나 원본 슬라이드 덱 열람을 전제하지 않습니다. 기업의 성과 주장, 연구 결과, 이 자료의 해설을 구분하며, 각 장에 원자료와 영상 타임스탬프를 연결합니다. 전체 전사문·비공개 자료·개인화된 업무 맥락은 포함하지 않습니다. 삼성전자의 공식 발표자료가 아닙니다.

## 로컬 실행

설치나 빌드 없이 `index.html`을 브라우저에서 열 수 있습니다. CSS와 JavaScript를 문서에 포함하며 외부 폰트·스크립트·추적기·런타임 의존성은 없습니다. JavaScript를 끈 경우에도 전체 본문을 읽을 수 있습니다.

저장소 루트에서 정적 서버를 실행하려면:

```sh
python3 -m http.server 8000
```

그다음 `http://localhost:8000/saif-2026-seminar/`를 엽니다.

내용 구조·내부 앵커·기본 접근성·출처 링크 검증:

```sh
node saif-2026-seminar/validate.mjs
```

## 유지보수

`index.html`은 HTML 본문, 인라인 스타일, 인라인 스크립트로 구성됩니다. 새 장을 추가할 때는 고유 id, 제목 연결(`aria-labelledby`), 목차 링크, 장 번호를 함께 갱신합니다. 사실과 출처의 범위를 유지하고, 키보드 이동·모드 전환·작은 화면·인쇄를 다시 확인합니다.

공유 Pages workflow는 기존 두 Slidev 자료를 빌드한 뒤 이 디렉터리의 HTML을 검증하고 `_pages/saif-2026-seminar/index.html`로 복사합니다. 다른 세미나의 빌드나 경로는 변경하지 않습니다.
